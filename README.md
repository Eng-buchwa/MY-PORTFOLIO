# Nicolaus Buchwa Gilbert Portfolio

A responsive single-page portfolio for a full-stack software engineer, built with React, Vite, Tailwind CSS, Motion, and Lucide React.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

Portfolio content is centralized in `src/data/portfolio.js`. Contact details, CV location, project status, and optional live URLs should be updated there rather than inside components.
